# Provider-Neutral SDLC Plugin

This active plugin provides the portable `init-project` skill and the review persona agents. The delivery workflow skills (`milestone`, `spec`, `refine`, `plan`, `tdd`, `review`, `deliver`, `release`, `health`, `improve`, `explore`, `pair`) live in the `filipkrawiec-workflow` package of FilipKrawiec/skills. Host adapters and executor-control instructions are intentionally outside this package.
